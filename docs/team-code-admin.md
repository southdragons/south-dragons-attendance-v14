# チームコード 管理者向け手順

対象：South Dragons J.B.C 出欠管理（新アプリ）の運営者
画面の場所：「チーム管理」→ ログイン →「チームコード」

チームコードは、選手名・予定・出欠を見られる端末を、チームの保護者に限るためのものです。
出欠を入力できるかどうか（「利用端末」の承認）とは別の仕組みです。

## 1. 用語
| 用語 | 意味 |
|---|---|
| チームコード | `SD-XXXX-XXXX` の形式。チームLINEのノートで保護者に知らせる |
| 閲覧制限 | 有効にすると、コードを入力した端末だけが見られる。無効なら今までどおり誰でも見られる |
| 閲覧できる端末 | コードを入力した端末、出欠を入力できる端末（登録済み・承認済み）、管理者が追加した端末 |
| 利用端末（参加者管理） | 出欠を入力できる端末。今までどおり、承認・解除で管理する |

閲覧制限が無効の間は、「閲覧できる端末」は0台と表示されることがあります。出欠を入力できる端末は、閲覧制限を有効にした時点で自動的に追加され、コードを入力しなくても今までどおり使えます。

## 2. 初めて使うとき（運用開始時）
1. 「申請・登録の上限（スパム対策）」を有効にする（任意。推奨）。
2. 「コードを発行する」→ 確認 →「発行する」。
3. 表示されたコードを「コードをコピー」するか、メモする。**この画面でしか表示されません。**
4. 「コードを控えました」にチェックを入れて、「閉じる」。
5. チームLINEのノートに、次のURLとコードを、それぞれ別の行に載せる。
   - URL：`https://southdragons.github.io/south-dragons-attendance-v14/?openExternalBrowser=1`
   - コード：発行したもの
6. 保護者への案内（`docs/team-code-parents.md`）を共有する。
7. 案内を出すのと同時に、「閲覧制限を有効にする」→ 確認 →「有効にする」。

## 3. コードを変更するとき
- 「新しいコードに変更」を押す。前のコードは「すぐに使えなくする」か「24時間は使えるようにする」を選ぶ。
- すでにコードを入力した端末と、出欠を入力できる端末は、変更後もそのまま使えます。
- 新しいコードは一度だけ表示されます。チームLINEのノートを書き換えてください。
- 目安：年度やシーズンの変わり目に変更する。

## 4. 端末の閲覧を止めるとき
| 状況 | 操作 | 影響 |
|---|---|---|
| 特定の端末を止めたい（紛失・不審な端末） | 一覧の端末の「取り消す」 | その端末だけ、次に開いたときにコードの入力が必要になる |
| コードが少し漏れた | ①「新しいコードに変更」②「閲覧だけの端末を停止」 | 出欠を入力できない端末（祖父母など閲覧だけの端末）が、新しいコードの入力を求められる |
| 広く漏れた、範囲がわからない | ①「新しいコードに変更」②「全端末に再入力を求める」 | 全員が新しいコードを一度入力する。**出欠の入力権限と端末共有は消えない**ので、承認し直しは不要 |

- 閲覧を止めても、その端末で出欠を入力する権限（利用端末）は残ります。入力もできなくしたいときは、「参加者管理」→ 選手の「利用端末」→「権限を解除」も行ってください。
- 不審な端末追加申請は、申請者名と続柄を、LINEなど別の方法で本人に確かめてから承認してください。
- 開いたままの画面は、次に操作したとき、またはアプリに戻ったとき（最短1分おき）に、コード入力画面へ切り替わります。

## 5. 管理者の端末について
- 管理者としてログインしている間は、コードがなくても全データを見られます。
- ログアウトすると、その端末が「閲覧できる端末」に入っていなければ、コード入力画面になります。
- 管理者の端末で今後も見たいときは、「この端末を追加」を押すか、保護者と同じくコードを入力してください。
- 管理パスワードを変更すると、すべての管理者がログアウトされます。

## 6. 困ったとき
| 症状 | 対処 |
|---|---|
| 保護者が「チームコードが正しくありません」 | チームLINEのノートが最新のコードか確認する |
| 「入力の回数が多すぎます」 | 15分ほど待ってから入力してもらう |
| 多くの保護者が入れない、など想定外の問題 | 「閲覧制限を無効にする」で、すぐに今までの状態に戻る |
| コードを控え忘れた | 「新しいコードに変更」で新しく発行する（入力済みの端末は影響なし） |
