# 出欠アプリの使い方（保護者向け）

South Dragons J.B.C の出欠は、このアプリで入力します。
チームLINEのノートに載っている **URL** と **チームコード**（`SD-` で始まる文字）を用意してください。

## 1. アプリを開く
- チームLINEのノートにあるURLをタップします。URLの末尾が `?openExternalBrowser=1` になっていれば、LINEの中ではなく、Safari（iPhone）やChrome（Android）で開きます。
- 「LINEアプリの中で開いています」と表示されたら、右上のメニューから「ブラウザで開く」を選んでください。LINEの中で登録すると、あとでブラウザで開いたときに、もう一度コードの入力や申請が必要になります。

## 2. iPhoneの方：ホーム画面に追加してから使う
iPhoneでは、**ホーム画面に追加したアプリと、Safariとで、記録が別々**になります。また、Safariでしばらく使わないと、記録が消えることがあります。次の順番で使い始めてください。
1. SafariでURLを開く。
2. 画面下の共有ボタン（四角から矢印が出ているマーク）→「ホーム画面に追加」→「追加」。
3. **ホーム画面の「SD」アイコンから開く。**
4. ここで、次の「3. チームコードを入力」と「4. 選手を登録」を行う。
5. 次回からも、ホーム画面のアイコンから開いてください。

Androidの方は、Chromeのメニュー →「ホーム画面に追加」で追加できます（Chromeと記録は共通です）。

## 3. チームコードを入力
1. 「チームコードを入力してください」の画面で、コードを入力します（小文字・ハイフンなしでも大丈夫です）。
2. 「お名前・続柄」は任意です（例：山田（母））。運営者が端末を見分けるために使います。
3. 「確認する」を押すと、予定と出欠の一覧が表示されます。この端末では、次回から入力は不要です。

表示されるメッセージ：
| メッセージ | 対処 |
|---|---|
| チームコードが正しくありません | チームLINEのノートのコードを確認して、もう一度入力 |
| 入力の回数が多すぎます | 15分ほど待ってから入力 |
| 通信できませんでした | 電波の良い場所で、もう一度 |
| サーバーが一時的に応答していません | しばらく待ってから、もう一度 |
| この端末の確認ができませんでした | ページを再読み込み。直らない場合は運営者へ |

## 4. 選手（お子さま）を登録する ― 最初の保護者
1. 「はじめての方はこちら」→「名前を登録する」。
2. お子さまの名前を入力して「登録する」。
3. 兄弟がいる場合は「兄弟・選手を追加」から、ひとりずつ追加します。
4. 表の自分の子どもの欄（○・×・未）をタップして、出欠を選びます。

## 5. 2人目の保護者（両親とも入力したい場合）
1. 2人目の方も、1〜3の手順でアプリを開き、チームコードを入力します。
2. 「名前を登録する」で、**同じお子さまの名前**を入力します。
3. 「すでに登録されています」と表示されたら、申請者のお名前と続柄（父・母など）を入力して、「この端末の利用を申請する」。
4. 運営者が承認すると、両方の端末から同じ出欠を入力・変更できます（最後に保存した内容が反映されます）。
5. 承認されるまでは、一覧の閲覧はできますが、出欠の入力はできません。

## 6. 機種変更・ブラウザの記録を消したとき
- 新しい端末（または記録を消した端末）では、チームコードの入力からやり直してください。
- 出欠を入力するには、5の「この端末の利用を申請する」で申請し、運営者の承認を待ってください。今までの出欠は消えません。

## 7. 気をつけること
- チームコードとURLは、チームの外の人に転送しないでください。
- プライベートブラウズ（シークレットモード）では使わないでください（閉じると記録が消えます）。
- 退団した選手は一覧に表示されず、入力もできません。過去の記録は残ります。
